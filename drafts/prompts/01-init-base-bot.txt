Создай базовую структуру проекта и Telegram-бота без памяти на Python 3.11 в папке `VPg01-llm-memory-bot`.

ВАЖНО:
1. Никаких коммитов и пушей в Git без моего прямого указания. Просто создавай/изменяй файлы.
2. Перед созданием каждого файла напиши, что именно ты собираешься сделать. После выполнения — кратко подтверди, что файл записан.
3. Не трогай файлы, которые не просили трогать. Никаких «улучшений» и «аудитов» соседних файлов.
4. Код должен быть production-ready: с обработкой ошибок (try/except) и docstrings.

Создай папку `VPg01-llm-memory-bot` и внутри неё следующие файлы:

1. `requirements.txt` — зависимости:
   - python-telegram-bot[job-queue]
   - openai
   - python-dotenv

2. `.env.example` — пример переменных окружения:
   OPENAI_API_KEY=your_api_key
   OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1
   OPENAI_MODEL=gpt-5.6-luna
   TEMPERATURE=1
   LOG_LEVEL=INFO
   BOT_TOKEN=your_bot_token

3. `main.py` — основной файл бота:
   - Загружает переменные из `.env` через `python-dotenv`.
   - Настраивает логирование через `logging` (уровень из `LOG_LEVEL`, формат: время, уровень, имя, сообщение; вывод в stdout).
   - Инициализирует клиент OpenAI с `api_key` и `base_url` из окружения.
   - Реализует асинхронный обработчик сообщений (python-telegram-bot v20+):
     - получает текст сообщения пользователя;
     - отправляет запрос к модели (без истории, только текущее сообщение + системный промпт «Ты полезный AI-ассистент. Отвечай по делу.»);
     - возвращает ответ пользователю через `message.reply_text`.
   - Все ошибки (сеть, API, парсинг) ловятся в try/except, логируются через `logger.error`, пользователю отправляется сообщение об ошибке.
   - Настраивает и запускает polling.

4. `Dockerfile`:
   - Базовый образ `python:3.11-slim`.
   - Рабочая директория `/app`.
   - Копирование `requirements.txt`, установка зависимостей (`pip install --no-cache-dir -r requirements.txt`).
   - Копирование `main.py`.
   - Создание непривилегированного пользователя и переключение на него.
   - Команда запуска `CMD ["python", "main.py"]`.

5. `docker-compose.yml`:
   - Сервис `base-bot` (сборка из текущей директории).
   - Проброс `.env` через `env_file`.
   - `restart: unless-stopped`.
   - Отдельная сеть `telegram-bots-network` (driver: bridge).
