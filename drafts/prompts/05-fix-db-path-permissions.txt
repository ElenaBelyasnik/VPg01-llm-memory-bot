05-fix-db-path-permissions.txt

В контейнере bot-memory возникает ошибка `sqlite3.OperationalError: unable to open database file` при попытке создать БД по пути `/app/data/bot_memory.db`. Причина: папка `/app/data` не существует внутри контейнера до момента запуска, и пользователь appuser не имеет прав на её создание.

ВАЖНО:
1. Никаких коммитов и пушей в Git без моего прямого указания. Просто создавай/изменяй файлы.
2. Перед изменением файла напиши, что именно ты собираешься сделать. После выполнения — кратко подтверди, что файл записан.
3. Не трогай файлы, которые не просили трогать.

Твоя задача:
1. Открой файл `Dockerfile`.
2. Найди строку, где создаётся пользователь (после `useradd ...`). Добавь создание папки `/app/data` и назначение прав:
   `RUN mkdir -p /app/data && chown -R appuser:appuser /app/data`
   (или объедини с существующей командой `RUN groupadd ... && useradd ... && chown -R ... && mkdir -p /app/data && chown -R appuser:appuser /app/data`).
3. Сохрани файл.

Дополнительно проверь, что в `docker-compose.yml` для сервиса `bot-memory` volume `bot-memory-data` монтируется в `/app/data`. Это уже должно быть, но убедись, что путь совпадает.
